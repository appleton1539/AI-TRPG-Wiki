# AI TRPG LLM Wiki

繁體中文入門知識庫，主題為 AI 如何協助桌上角色扮演遊戲（TRPG），並附有 16 頁互動式 HTML 教學簡報。

## 專案內容
- `wiki/`：TRPG、LLM、AI GM、角色規則、RAG 與跑團流程知識文章
- `raw/sources.md`：參考來源與來源摘要
- `presentation/index.html`：互動式教學簡報
- `presentation/outline.md`、`presentation/slides.md`：簡報大綱與來源對照
- `AGENTS.md`：內容規範與完成定義
- `workflow.mmd`：建置流程圖
- `logs/quality_check.md`：品質檢查紀錄

## 使用
直接開啟 `presentation/index.html`，或透過 GitHub Pages 瀏覽部署版本。簡報支援鍵盤方向鍵、骰子互動與角色建立示範。

所有骰子公式均為教學示例，不代表所有 TRPG 系統的通用規則。
